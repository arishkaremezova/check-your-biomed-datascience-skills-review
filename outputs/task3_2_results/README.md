# 3.2. Кластеризация тканей

Для каждого изображения вычислен 21 признак. По каждому из трёх цветовых каналов взяты 10-й, 50-й и 90-й процентили, стандартное отклонение и средние перепады яркости на расстояниях 1, 3 и 6 пикселей. Направления по горизонтали и вертикали усреднены. Так цвет и мелкая текстура учитываются независимо от положения ткани в кадре.

Масштабирование и KMeans обучены на 3 600 изображениях. У KMeans девять кластеров и 20 инициализаций, случайное зерно 42. Тем же преобразованием и кластеризатором обработаны 900 отложенных изображений. Метки тканей прочитаны после назначения кластеров.

На всех 3 600 обучающих изображениях ARI составил 0,186, NMI — 0,339. Silhouette по евклидовым расстояниям в стандартизованном пространстве признаков равен 0,288. Для сравнения, базовый KMeans из примера репозитория на развёрнутых пикселях дал ARI 0,147 и NMI 0,281 на тех же изображениях.

Кластер 5 почти полностью состоит из фона (219 из 220 изображений). Кластер 8 объединяет, среди прочего, гладкую мышечную ткань (163), строму (155) и слизь (143). Сходство по цвету и текстуре лишь частично совпадает с делением на типы ткани.
