# 3.1. Классификация тканей

Из 7 200 изображений 5 760 использованы для обучения, 1 440 для валидации. Стратифицированное разбиение сохранило доли девяти классов. Значения RGB разделены на 255, затем из них вычтено 0,5, а результат разделён на 0,5.

У CNN три свёрточных блока с 24, 48 и 72 каналами. В каждом блоке две свёртки 3×3, нормализация, ReLU и слой максимального пулинга. После глобального усреднения линейный слой выдаёт девять оценок. Для обучения использованы AdamW и перекрёстная энтропия. Разница в численности классов умеренная, от 505 до 824 обучающих примеров на класс. Веса классов одинаковые. Лучшая эпоха выбиралась по macro F1, чтобы каждый класс одинаково влиял на выбор модели.

Лучший результат получен на 11-й эпохе. На валидации модель верно классифицировала 1 305 из 1 440 изображений. Accuracy составила 0,906, macro F1 — 0,905. Обучение остановилось после пяти эпох без улучшения. Самый низкий F1 у стромы, связанной с опухолью (0,816). Самая низкая полнота у нормальной слизистой оболочки кишки (0,746). Модель распознала 94 из 126 её примеров. Эталонных меток для 1 800 отложенных изображений в архиве нет.
